Lab

무엇을 확인할지는 사람,
어떻게 확인할지는 Agent.

Agent가 평가 기준까지 멋대로 정하지 않습니다. 먼저 문서와 공개 artifact를 조사한 뒤, 사용자가 “이걸 실제로 써본다면 무엇이 궁금한지”를 함께 좁히고 그 목적에 맞는 검증 실험을 설계합니다.

What do you want to know?

Agent가 먼저 확인 가능한 질문을 제안하고, 사용자는 자신의 용도에 맞는 기준을 선택하거나 직접 입력합니다.

내 Mac에서 실제로 돌아가나? 문서에 적힌 기능이 전부 공개됐나? 이 모델은 어떤 입력에 약한가? 실제 latency는 어떤가? 직접 질문하기…

The agent turns your question into a trial.

사용자의 질문을 검증 가능한 성공 조건과 실행 계획으로 바꿉니다.

1. Questionwhat the user wants to know
2. Planevidence + acceptance criteria
3. Tool callsrepo · package · runtime tools
4. Run safelyOpenShell sandbox
5. Observeresults + failures → evidence
NVIDIA agent stack

Research부터 safe execution까지,
NVIDIA 기술로 연결합니다.

AI-Q는 조사와 검증 계획의 근거를 만들고, NVIDIA NIM 기반 Nemotron은 추천 질문을 확장하고 실행 결과를 해석합니다. NemoClaw는 실행 환경을 오케스트레이션하며, OpenShell은 tool use와 code execution에 안전 경계를 강제합니다.

RESEARCH · PLAN
Q
NVIDIA AI-Q

다출처 조사와 인용을 바탕으로 실제로 확인해야 할 내용을 좁히고, 사용자 질문에 맞는 검증 계획의 근거를 만듭니다.

QUESTION · EVIDENCE
N
Nemotron · NIM

Research 근거를 바탕으로 룰 기반 추천 질문을 확장하고, 실행 결과를 합의된 검증 기준과 대조해 해석합니다.

ORCHESTRATE
NC
NemoClaw

local-first agent runtime과 OpenShell sandbox lifecycle을 관리해 계획을 실제 실행 단계로 연결합니다.

SAFE EXECUTION
S
OpenShell

Deny-by-default network와 제한된 filesystem/process policy로 Agent의 실제 행동을 안전하게 통제합니다.

Agentic AI

관심에서 시작해,
질문을 실제 검증으로 바꾸는 Agent.

AI-Q가 조사와 검증 계획의 근거를 만들고, Nemotron이 근거 기반 질문을 확장합니다. 사용자가 검증 방향을 정하면 필요한 도구를 호출해 안전한 환경에서 실행하고, 실행 후에는 실제 관측 결과를 합의된 기준과 대조해 Evidence로 남깁니다.

User flow

★ · ♥ · ↑에서
“직접 써봤다”까지.

01 · Signal
GitHub Star / Hugging Face Like · Upvote

사용자가 이미 남기고 있는 관심 신호를 별도의 프롬프트 없이 실험 후보로 가져옵니다.

02 · Resolve
Paper · Repo · Model · Dataset · Demo 연결

흩어진 artifact를 하나의 기술 묶음으로 연결해 실제 검증 대상을 구성합니다.

03 · Research
문서가 말하는 기능과 실제 공개 범위를 조사

NVIDIA AI-Q가 여러 출처를 조사하고 인용을 보존해 검증에 필요한 근거를 모읍니다.

04 · Question
궁금한 질문을 선택하거나 직접 입력

조사 결과를 바탕으로 제안된 질문을 고르거나, 사용자가 직접 새로운 질문을 입력합니다.

05 · Plan + Tools
사용자 질문을 검증 기준과 실행 계획으로 구체화

질문의 목적에 맞는 Trial Plan을 만들고, repo·package·runtime 도구를 어떻게 사용할지 계획합니다.

06 · Execute
격리된 환경에서 실제 설치·실행

NemoClaw이 관리하는 OpenShell sandbox 안에서 execution agent가 도구를 호출합니다. 외부 네트워크는 기본 차단하고 trial에 필요한 주소만 허용합니다.

07 · Evidence
실행 결과를 문서상 정보와 나란히 비교

성공·실패, dependency, exit code, runtime, 허용/차단 endpoint와 transcript를 실제 관측 증거로 남깁니다.
